# Key cutting FAQ

**How much is a key copy?** A standard house or padlock key is $3.49 each.

**How long does it take?** About 5 minutes per key.

**Can you copy car keys?** We copy older car keys with no chip. We cannot copy keys with a chip or a remote, or program fobs.

**Can you copy a key stamped "Do Not Duplicate"?** No. We also do not copy restricted-keyway keys, which need written authorization from the lock owner.

**When does key cutting stop?** The counter stops taking new keys 30 minutes before the store closes.
