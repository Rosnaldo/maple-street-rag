# Return policy

We want you to be happy with every purchase.

- Most items can be returned within **30 days** with a receipt for a full refund.
- We cannot accept returns without a receipt.
- Power tools can be returned within 14 days only if the box is unopened.
- Tinted paint cannot be returned.
